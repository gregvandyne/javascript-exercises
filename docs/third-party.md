# Third-party code in the figure libraries

What Oomba Academy self-hosts for science, maths and graph figures (`docs/figures-api.md`), under which licence, and how
each licence was checked. Each folder keeps the package's own LICENSE file next to the one file games load, and a
`manifest.json` with the sha256 (and sha384, the SRI hash) of every file; `figures/SHIPPED.json` locks them all
(`server/services/figlibs.js` pins the script tags; `tests/unit/figures-vendor.test.js` checks files, hashes and
licences). Other vendored code (Three.js, Phaser, Rapier, fonts) is listed where it is pinned: `docs/decisions.md`,
`kit2/SHIPPED.json` and each folder's own licence file.

## How the licences were checked (19 Nov 2026)

- **JSXGraph 1.14.3.** `package.json` says `(MIT OR LGPL-3.0-or-later)`. The package ships both texts (`LICENSE.MIT`,
  `LICENSE.LGPL`, the same two in `distrib/`). We choose **MIT** and copy only `LICENSE.MIT` (the MIT text, © 2008-2012
  Matthias Ehmann, Michael Gerhaeuser, Carsten Miller, Bianca Valentin, Alfred Wassermann, Peter Wilfahrt), recorded as
  `usedUnder: "MIT"` in its manifest. The minified file also carries a small UTF-8 decoder by Bjoern Hoehrmann under
  the MIT licence, with its notice kept in the file.
- **SmilesDrawer 2.4.2.** `package.json` says `MIT`; `LICENSE.md` is the MIT text (© 2017 GDB / Reymond Research
  Group). Its one dependency, **chroma-js** (© 2011-2019 Gregor Aisch), is bundled into `smiles-drawer.min.js` under
  its BSD-3-Clause licence (its colour names under Apache-2.0); both notices are kept, unchanged, in the file's own
  "Bundled license information" comment.
- `scripts/vendor-figures.js` refuses a package whose `package.json` licence or LICENSE file is not the one checked
  here, and never copies a GNU licence text.

## STEM Figures, ported (21 Nov 2026)

- **What it is.** An open source set of worksheet figure generators (`teacherdotdev/stem-figures`). Its code is under the **Apache License 2.0**:
  `LICENSE.txt` at the repository root, the standard text with no copyright line filled in, there since its first
  commit (`6c42b9c`, 24 Sep 2026) and unchanged at `3bb43190`. It has no NOTICE file. The figures its sites make are a
  separate matter (CC0 1.0); Oomba states its own CC0 notice for figures made in Oomba (`docs/figures-api.md`).
- **Permission.** The owner of Oomba Academy has confirmed the project's permission for this port, and its owner asked
  for their name to be kept out of the product. So this record and the verbatim `figures/src/ported/LICENSE.txt` are
  the only places that name it; the ported files point here instead. Removing this record would breach Apache 2.0
  section 4 (keep the license and the attribution), so it stays.
- **How it is used (Apache 2.0 section 4).** (a) The license text is next to the ported code and in
  `public/vendor/oomba-figures/1.1.0/LICENSE`, `public/vendor/oomba-figures/1.2.0/LICENSE`, `public/vendor/oomba-figures/1.3.0/LICENSE`, `public/vendor/oomba-figures/1.4.0/LICENSE`, `public/vendor/oomba-figures/1.5.0/LICENSE` and `public/vendor/oomba-figures/1.7.0/LICENSE`, after ours. (b) Each ported file says at its top that it was changed
  and how; the minified `oomba-figures.js` and its packs (1.1.0 and later) keep each of those notes as a `/*! ... */` comment, so the shipped
  file says it too. (c) The original had no copyright, patent or trademark notices in the ported files to keep. (d) There is
  no NOTICE file to carry. Only the geometry and pure helpers are ported: no framework components, no apps, no hosting
  config, no analytics, no branding, no example pictures (they carry the project's own notice in their metadata).
- **Not taken.** The math input library the project vendors (its packages have no license file; its author is not
  the project's) is not copied, used or consulted: Oomba Figures takes structured data, so nothing needs to parse typed
  math, and the shapes' math labels are set by Oomba's own typesetter (`figures/src/mathtext.js`, MIT, written fresh). The project's composite shape editor is not ported either: `compositeShape` (`figures/src/composite.js`) is Oomba's own code. The data displays, probability figures and tables (`figures/src/data.js`, `figures/src/prob.js`) port only the statistics (`ported/stats.js`); their drawing is Oomba's own, and the protractor (`figures/src/protractor.js`) is written fresh (the project has none). The 3D solids, nets and mapping diagram (`figures/src/solids.js`, `figures/src/mapping.js`) port only the geometry and layout (`ported/solids.js`, `ported/nets.js`, `ported/mapping.js`); reading the data, the checks, the answers and the drawing are Oomba's own. The ruler (`reading` with `type: "ruler"`) ports only the marks and how a length is written (`ported/ruler.js`, from the math site's ruler-only copy); its checks and drawing in `figures/src/readings.js` are Oomba's own, and the magnifiers are not ported. The physics port (1.1.0) takes only the physics and math logic: the motion from segments (`ported/motion.js`), the projectile's path (`ported/projectile.js`), the wave's fitted axes and longitudinal lines (`ported/waves.js`), the series/parallel circuit tree (`ported/circuittree.js`, from the circuit generator's unused tree code) and the caliper's and micrometer's scales (`ported/gauges.js`, the length reading's one implementation shared by the physics and chemistry sites); reading the data, the checks, the answers (`OF.solve`), the circuit layout and every drawing (`figures/src/motion.js`, `projectile.js`, `waves.js`, `network.js`, `readings.js`, the plane mirror in `physics.js`) are Oomba's own. The coil and magnet generator (switched off on the live sites) is not ported, and the vector diagram is not ported twice (Oomba's `vectors`). The chemistry port (1.2.0) takes only the data and the logic: the elements and their configurations (`ported/elements.js`), the isotope table and its sums (`ported/isotopes.js`), the heating curve's physics (`ported/heating.js`), the reaction energy profile (`ported/profile.js`), the wavelength colors, element lines and binding energies (`ported/spectra.js`), the particle arrangements and lattices (`ported/particles.js`) and the lab instruments' scales (`ported/labware.js`); reading the data, the checks, the answers (`OF.solve`) and every drawing (`figures/src/spectra.js`, `energy.js`, `atoms.js`, `particles.js`, `labware.js`, `readings.js`, `chem.js`, `curves.js`) are Oomba's own. The organic structure editor (skeletal structures) is not ported (owner decision), and the dot-and-cross diagram (`dotCross` in `figures/src/atoms.js`) is Oomba's own code, drawn from the Lewis structures' data; the source's dot-and-cross code is not ported. The biology port (1.3.0) takes only the models and data: population growth (`ported/growth.js`), the predator-prey cycles (`ported/lotka.js`), the enzyme and photosynthesis rates (`ported/rates.js`), the Punnett square's genetics (`ported/punnett.js`, alleles as tokens, not typed text), the pedigree's genetics, random families and layout (`ported/pedigree.js`), base pairing and the genetic code (`ported/dna.js`), osmosis (`ported/osmosis.js`), the gel's migration and ladders (`ported/gel.js`) and the micropipette (`ported/pipette.js`); reading the data, the checks, the answers (`OF.solve`) and every drawing (`figures/src/ecology.js`, `rates.js`, `genetics.js`, `molecular.js`, `osmosis.js`, `pipette.js`) are Oomba's own. The cell diagram, cell division, food web (with its bundled organism pictures) and microscope field of view generators are not ported (switched off on the live site; owner decision), and the source's math input field is not used (Oomba takes structured data). The economics port (1.4.0) takes only the models: the curve math (`ported/econcurves.js`), the supply and demand shapes and the money markets' curves (`ported/markets.js`), the AD-AS, Phillips curve and business cycle models (`ported/macro.js`) and the firm's costs and the production possibilities curve (`ported/firm.js`); reading the data, the checks, the answers (`OF.solve`), the label placement, the shift arrows, the hatching and every drawing (`figures/src/econ.js`, `markets.js`, `macro.js`, `firm.js`) are Oomba's own. The source's label placer, panel layout, settings and address format are not ported. Since 1.1.0 the bundle is split by subject: the ported parts are in the core or the pack file their kinds are in, each with its note. For 1.5.0, only the organic structure editor's views are ported (`ported/organic.js`): its pointer editing (drawing, dropping, rings, moving, swinging hydrogens), its page and its storage are not; the SMILES-lite reading, the automatic layout, the checks, the answers and the drawing (`figures/src/skeletal.js`) and the atomic energy levels (`figures/src/levels.js`, the project has no such generator) are Oomba's own code. For 1.7.0 (at commit `9ed3093`, after review fixes `9e725a0`, `86d40c0` and `4e74759`), the seven physics generators added since the first port and the cladogram are ported for their logic and layout only: the field tracing (`ported/fields.js`), circular motion's sizes (`ported/circular.js`), the lever's sums (`ported/lever.js`), the beam's torques (`ported/moments.js`), the pendulum's layout (`ported/pendulum.js`), the spring's coil (`ported/spring.js`), the track curve (`ported/track.js`) and the cladogram's tree and layout (`ported/clado.js`). Reading the data, the checks, every answer (`OF.solve`: the source's figures work out no speeds, energies, periods or spring forces, so those sums are Oomba's own), the label placement and all drawing (`figures/src/circular.js`, `fields.js`, `lever.js`, `torque.js`, `pendulum.js`, `spring.js`, `coaster.js`, `cladogram.js`, `mech.js`) are Oomba's own. The shared support hatching (`f337ad2`), the label placer, the settings and address format, the Svelte components, the tree editor's pointer edits, the example pictures and the chemistry generators of the same span (the 1.6.0 port) are not taken here.

## What we did not vendor

- **matter-js** (MIT): not needed. Phaser 3.90, already vendored for Kit 2 (`public/vendor/kit2/phaser/3.90.0/`, MIT),
  bundles Matter physics for moving physics in arcade games.
- **CircuitJS** and **PhET** simulations: GPL, never vendored. Circuit symbols are drawn by Oomba Figures itself.
- **Ketcher**: far too large for a game frame.
- Worksheet figure sites whose figures are CC0 but whose code has no open licence: none of their code or bundles was
  copied or consulted; every figure here is drawn by our own code or the libraries above.
  **Correction (21 Nov 2026):** the example sites behind that 19 Nov 2026 note were, by the evidence, STEM Figures
  (the same figure kinds: free-body, ray, circuit, motion graph, Bohr, Lewis, scale readings, half-life, titration;
  several sister sites; CC0 figures). Its code was open: Apache 2.0 since its first commit (24 Sep 2026). With the
  owner's confirmed permission it is now ported under that license (above). The rule itself stands for every other
  site: code without an open license is never copied or consulted.
