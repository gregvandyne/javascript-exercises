# /compare sources

Every cell of the comparison table on /compare (server/routes/compare.js), with where it comes from. Checked: 2026-11-22.

## What could not be checked

On 2026-11-22 none of the three public websites could be reached from the network this page was built on: every request to kahoot.com, classroomscreen.com and www.brainingcamp.com failed before connecting (the host did not resolve: it is not on this session's allowed network list). So no page of theirs was read, and every cell for the three products is **Not stated**, with no quote. Search-engine summaries and third-party listings were not used: a cell needs the product's own page.

To fill a cell: open the page listed under "Where to look", copy the exact supporting words, and add `{ s, src: { url, checked, quote } }` to `CELLS` in server/routes/compare.js (tests/unit/compare.test.js checks the source is on their own site and has a quote), then update `COMPARE_CHECKED`.
